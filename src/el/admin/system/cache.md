# Cache

<span class="sidebar-path">Μενού ιστότοπου → Cache</span>

Το ηλεκτρονικό κατάστημα κρατά έτοιμες σελίδες και δεδομένα σε προσωρινή μνήμη (cache) για να εξυπηρετεί γρήγορα τους επισκέπτες. Οι περισσότερες αλλαγές φτάνουν στο κατάστημα μόνες τους μέσα σε λίγα λεπτά· η σελίδα Cache είναι για όταν το χρειάζεστε τώρα. Μπορεί να την ανοίξει κάθε χρήστης του διαχειριστικού, και το Προσωπικό.

## Γιατί μια αλλαγή δεν φαίνεται

Ανάμεσα στο διαχειριστικό και τον επισκέπτη υπάρχουν δύο caches:

1. **Η cache δεδομένων.** Απαντήσεις όπως λίστες προϊόντων και δέντρα κατηγοριών κρατούνται για λίγο.
2. **Η cache του καταστήματος.** Κρατούνται και τα δεδομένα που έφερε το κατάστημα και οι **έτοιμες σελίδες**. Οι σελίδες προϊόντων και καταλόγου ξαναχτίζονται το πολύ κάθε πέντε λεπτά, οι σελίδες blog κάθε δέκα, η αρχική κάθε πέντε, οι στατικές σελίδες παρουσίασης κάθε μία ώρα και οι ρυθμίσεις περίπου κάθε λεπτό.

Επίσης, ο δικός σας browser μπορεί να δείχνει αποθηκευμένη σελίδα. Κάντε ανανέωση παρακάμπτοντας την cache (Ctrl+Shift+R) πριν υποθέσετε ότι φταίει ο server.

Πολύ λίγα καθαρίζουν μόνα τους. Η αποθήκευση ενός **τρόπου πληρωμής**, σε οποιαδήποτε γλώσσα, καθαρίζει τις επιφάνειες τρόπων πληρωμής και επιλογών αποστολής, γιατί το checkout εμφανίζει το κείμενο που γράψατε. Η αποθήκευση προϊόντος, κατηγορίας, επιμελημένης σχέσης προϊόντων ή θέσης προτάσεων καθαρίζει την επιφάνεια **Προτάσεις προϊόντων**. Αυτά είναι όλα: η τιμή, το απόθεμα και οι εικόνες ενός προϊόντος *δεν* καθαρίζονται με την αποθήκευση του προϊόντος, γιατί μια μαζική εισαγωγή καταλόγου θα σάρωνε τότε την cache μία φορά ανά γραμμή. Όλα τα υπόλοιπα περιμένουν να λήξει ο χρόνος τους ή χειροκίνητη εκκαθάριση.

## Τι βλέπετε

Η σελίδα παραθέτει **επιφάνειες**, ομαδοποιημένες σε κατάλογο, εμπόριο, ρυθμίσεις και περιεχόμενο. Κάθε κάρτα δείχνει το όνομα της επιφάνειας, μια περιγραφή του τι καλύπτει, το τρέχον πλήθος αποθηκευμένων εγγραφών και ποιες άλλες επιφάνειες σχετίζονται.

| Επιφάνεια | Εκκαθαρίστε αφού αλλάξετε | Καθαρίζει επίσης |
|---|---|---|
| **Προϊόντα** | προϊόν, εικόνες, χαρακτηριστικά, τιμή ή απόθεμα· και την αναζήτηση. | Κατηγορίες, Ετικέτες, και τα feeds προϊόντων για Meta, TikTok και πράκτορες AI. |
| **Κατηγορίες** | κατηγορία, εικόνα της, το δέντρο, ή τον χάρτη κατηγοριών πίσω από το μενού. | τα ίδια feeds προϊόντων. |
| **Τρόποι πληρωμής** | διαθεσιμότητα, κόστος, περιγραφή ή οδηγίες ενός τρόπου πληρωμής. | Επιλογές αποστολής, που περιέχουν τους επιτρεπτούς τρόπους. |
| **Επιλογές αποστολής** | πάροχο αποστολών, τιμή αποστολής, ή συγχρονισμό σταθμών/θυρίδων. Η αποθήκευση παρόχου ή τιμής την καθαρίζει αυτόματα, μαζί με τη λίστα χωρών. | |
| **Περιοχές & Χώρες** | σπάνια χρειάζεται· τους επιλογείς διεύθυνσης στο checkout. | |
| **Πιστότητα** | βαθμίδες ή ρυθμίσεις πιστότητας που εμφανίζονται στο κατάστημα. Αποθηκεύεται μόνο η πλευρά του καταστήματος, οπότε η εκκαθάριση είναι ελαφριά. | |
| **Προσφορές** | προσφορά, τους κωδικούς ή το χρονικό της παράθυρο. Καλύπτεται και η δημόσια σελίδα προσφορών. | |
| **Προτάσεις προϊόντων** | επιμελημένες σχέσεις ή θέσεις. Καθαρίζεται μόνη της στην αποθήκευση. | |
| **Blog** | άρθρα, κατηγορίες, ετικέτες, συγγραφείς, σχόλια. | |
| **Σελίδες & πλοήγηση** | διάταξη σελίδας, ιδιότητες ενότητας, σελίδα περιεχομένου ή μενού, και τις έτοιμες σελίδες που χτίζονται από αυτά. | |
| **Ετικέτες** | ετικέτες, που τις μοιράζονται προϊόντα και άρθρα. | |
| **Sitemap & SEO** | οτιδήποτε πρέπει να εμφανιστεί αμέσως στο sitemap, στο RSS ή στο ευρετήριο για AI. | |
| **Ρυθμίσεις ιστότοπου** | οποιαδήποτε Πρόσθετη Ρύθμιση, και την ταυτότητα πωλητή στο υποσέλιδο. | Τρόποι πληρωμής, Επιλογές αποστολής και Πιστότητα. |
| **Μεταφράσεις (parler)** | σημειωμένη ως **Βαρύ**. Αναγκάζει κάθε μεταφρασμένη γραμμή να ξαναδιαβαστεί από τη βάση. Μόνο όταν σας ζητηθεί. | |

Κάτω από τις κάρτες: οι είκοσι πιο πρόσφατες εκκαθαρίσεις του καταστήματός σας (ποιος, πότε, ποιες επιφάνειες, πόσες εγγραφές). Εμφανίζονται μόνο οι δικές σας — οι εκκαθαρίσεις άλλου καταστήματος δεν φαίνονται ποτέ εδώ, ούτε οι δικές σας σε εκείνο.

Αν η εκκαθάριση της πλευράς του καταστήματος δεν είναι ρυθμισμένη για το περιβάλλον, η σελίδα το λέει και καθαρίζεται μόνο η πλευρά των δεδομένων.

## Εργασίες

### Εκκαθάριση μιας περιοχής

1. Ανοίξτε το μενού ιστότοπου (το όνομα του καταστήματος στην κορυφή του μενού) και πατήστε **Cache**.
2. Τσεκάρετε την επιφάνεια ή τις επιφάνειες που αλλάξατε. Πάνω από τις κάρτες υπάρχουν **Επιλογή όλων** και **Καμία επιλογή**.
3. Το **Συμπερίληψη σχετικών επιφανειών** είναι τσεκαρισμένο από προεπιλογή και καθαρίζει και ό,τι βρίσκεται στη στήλη «Καθαρίζει επίσης» παραπάνω. Ξετσεκάρετέ το για πιο στενή εκκαθάριση.
4. Πατήστε **Εκκαθάριση επιλεγμένων**.

Ένα πράσινο μήνυμα αναφέρει πόσες εγγραφές αφαιρέθηκαν από κάθε πλευρά. Ένα κόκκινο σημαίνει ότι η cache δεδομένων δεν απάντησε και οι εγγραφές της παραμένουν· ένα κίτρινο ότι δεν ήταν δυνατή η επικοινωνία με το κατάστημα.

### Προεπισκόπηση πριν την εκκαθάριση

Τσεκάρετε τις επιφάνειες και πατήστε **Δοκιμαστική εκτέλεση**. Το μήνυμα δείχνει πόσες εγγραφές **θα** αφαιρούνταν και δεν διαγράφεται τίποτα. Οι ζωντανοί μετρητές ενημερώνονται καθώς τσεκάρετε.

### Εκκαθάριση όλων

Το **Εκκαθάριση όλων** ζητά επιβεβαίωση και μετά αφαιρεί κάθε επιφάνεια εκτός από τις **Μεταφράσεις (parler)**, που δεν συμπεριλαμβάνονται ποτέ ούτε στο **Εκκαθάριση όλων** ούτε στις σχετικές επιφάνειες και καθαρίζονται μόνο αν τις τσεκάρετε εσείς. Η ολική εκκαθάριση είναι ασφαλής αλλά κάνει τα επόμενα αιτήματα του καταστήματος πιο αργά όσο ξαναχτίζονται οι σελίδες. Προτιμήστε στοχευμένη εκκαθάριση μέσα στις ώρες λειτουργίας.

## Καλό είναι να ξέρετε

- Η εκκαθάριση δεν αλλάζει δεδομένα. Αν η ίδια η αλλαγή είναι λάθος, η εκκαθάριση απλώς θα δείξει το λάθος πιο γρήγορα.
- Η εκκαθάριση δεν επηρεάζει την cache του browser του πελάτη ούτε ένα CDN μπροστά από τον ιστότοπο· ο πελάτης ίσως χρειαστεί να ανανεώσει.
- Τα αποτελέσματα αναζήτησης έρχονται από το ευρετήριο της μηχανής αναζήτησης, όχι από αυτή την cache· ένα προϊόν που δεν εμφανίζεται στην αναζήτηση ξαναμπαίνει στο ευρετήριο με την αποθήκευση και με νυχτερινή εργασία.
- Τα feeds προϊόντων για Meta, TikTok και πράκτορες AI ανανεώνονται καθαρίζοντας Προϊόντα ή Κατηγορίες.
- Κάθε εκκαθάριση, ακόμη και δοκιμαστική, καταγράφεται στο κατάστημα που την έκανε. Οι τελευταίες είκοσι δικές σας εμφανίζονται σε αυτή τη σελίδα, ενώ η πλήρης καταγραφή όλων των καταστημάτων βρίσκεται στην κονσόλα της πλατφόρμας. Η λίστα μετρά μόνο τις εκκαθαρίσεις από τότε που έγινε ανά κατάστημα, οπότε στην αρχή μπορεί να είναι κενή.
- Πλήρης εκκαθάριση τρέχει και αυτόματα την 1η κάθε μήνα στις 04:00.
