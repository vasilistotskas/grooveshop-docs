# Cache

<span class="sidebar-path">Μενού ιστότοπου → Cache</span>

Το ηλεκτρονικό κατάστημα κρατά σελίδες και απαντήσεις του API σε προσωρινή μνήμη (cache) για να εξυπηρετεί γρήγορα τους επισκέπτες. Οι περισσότερες αλλαγές φτάνουν στο κατάστημα μόνες τους μέσα σε λίγα λεπτά· η σελίδα Cache είναι για όταν το χρειάζεστε τώρα. Μπορεί να την ανοίξει κάθε χρήστης του διαχειριστικού (`admin/admin.py`, `clear_cache_view`).

## Γιατί μια αλλαγή δεν φαίνεται

Ανάμεσα στο διαχειριστικό και τον επισκέπτη υπάρχουν δύο cache:

1. **Η cache του API** (Django, Redis). Απαντήσεις όπως λίστες προϊόντων και δέντρα κατηγοριών κρατούνται για λίγο.
2. **Η cache του ηλεκτρονικού καταστήματος** (Nuxt). Κρατούνται και τα JSON που έφερε το κατάστημα και το **έτοιμο HTML** πολλών σελίδων. Οι σελίδες προϊόντων ξαναχτίζονται το πολύ κάθε πέντε λεπτά, οι σελίδες blog κάθε δέκα και οι ρυθμίσεις περίπου κάθε λεπτό.

Επίσης, ο δικός σας browser μπορεί να δείχνει αποθηκευμένη σελίδα. Ανανεώστε παρακάμπτοντας την cache (Ctrl+Shift+R) πριν υποθέσετε ότι φταίει ο server.

Κάποιες εγγραφές εκκαθαρίζουν μόνες τους (`core/cache/invalidation.py`, `admin/signals.py`): η αποθήκευση μεθόδου πληρωμής, προϊόντος, κατηγορίας, σχέσης προϊόντων ή θέσης προτάσεων εκκαθαρίζει τις επιφάνειες που εξαρτώνται από αυτά, και κάθε εγγραφή παραγγελίας ή αποθέματος ανανεώνει τα νούμερα του πίνακα ελέγχου. Όλα τα υπόλοιπα περιμένουν να λήξει ο χρόνος τους ή χειροκίνητη εκκαθάριση.

## Τι βλέπετε

Η σελίδα εμφανίζει **επιφάνειες**, ομαδοποιημένες σε catalog, commerce, config και content. Κάθε κάρτα δείχνει το όνομα της επιφάνειας, περιγραφή του τι καλύπτει, τον ζωντανό αριθμό κλειδιών που είναι αποθηκευμένα αυτή τη στιγμή και ποιες άλλες επιφάνειες σχετίζονται.

| Επιφάνεια | Εκκαθαρίστε αφού αλλάξετε |
|---|---|
| **Προϊόντα** | ένα προϊόν, τις εικόνες, τα χαρακτηριστικά, την τιμή ή το απόθεμά του. Ανανεώνει και τα feeds προϊόντων για Meta, TikTok και πράκτορες. |
| **Κατηγορίες** | μια κατηγορία, την εικόνα της ή το δέντρο. Ανανεώνει και τα feeds. |
| **Μέθοδοι πληρωμής** | τη διαθεσιμότητα, το κόστος ή την περιγραφή μιας μεθόδου πληρωμής. |
| **Επιλογές αποστολής** | έναν πάροχο αποστολών, μια τιμή αποστολής, ή μετά από συγχρονισμό καταστημάτων ή lockers. |
| **Περιφέρειες & Χώρες** | σπάνια χρειάζεται· οι επιλογείς διεύθυνσης. |
| **Πιστότητα** | επίπεδα ή ρυθμίσεις πιστότητας που εμφανίζονται στο κατάστημα. |
| **Προσφορές** | μια προσφορά, τους κωδικούς ή το πρόγραμμά της. Καλύπτεται η σελίδα προσφορών. |
| **Product recommendations** | επιμελημένες σχέσεις ή θέσεις. Εκκαθαρίζεται μόνη της στην αποθήκευση. |
| **Blog** | άρθρα, κατηγορίες, ετικέτες, συντάκτες, σχόλια. |
| **Pages & navigation** | μια διάταξη σελίδας, τις ιδιότητες μιας ενότητας, μια σελίδα περιεχομένου ή ένα μενού. |
| **Ετικέτες** | ετικέτες κοινές σε προϊόντα και άρθρα. |
| **Sitemap & SEO** | οτιδήποτε πρέπει να εμφανιστεί αμέσως στο sitemap, στο RSS ή στο ευρετήριο για AI. |
| **Ρυθμίσεις ιστότοπου** | οποιαδήποτε Πρόσθετη Ρύθμιση, και την ταυτότητα πωλητή του υποσέλιδου. |
| **Μεταφράσεις (parler)** | σημειωμένη ως **Βαρύ**. Αναγκάζει κάθε μεταφρασμένη γραμμή να ξαναδιαβαστεί από τη βάση. Μόνο όταν σας ζητηθεί. |

Κάτω από τις κάρτες: οι είκοσι πιο πρόσφατες εκκαθαρίσεις (ποιος, πότε, ποιες επιφάνειες, πόσα κλειδιά).

Αν η εκκαθάριση του ηλεκτρονικού καταστήματος δεν έχει ρυθμιστεί για το περιβάλλον, η σελίδα το αναφέρει και εκκαθαρίζεται μόνο το μισό του API.

## Εργασίες

### Εκκαθάριση μιας περιοχής

1. Ανοίξτε το μενού ιστότοπου (όνομα καταστήματος στην κορυφή του μενού) και πατήστε **Cache**.
2. Επιλέξτε την επιφάνεια ή τις επιφάνειες που αλλάξατε. Τα **Επιλογή όλων** και **Καμία επιλογή** βρίσκονται πάνω από τις κάρτες.
3. Το **Συμπερίληψη σχετικών επιφανειών** είναι προεπιλεγμένο και εκκαθαρίζει και τις επιφάνειες που δηλώνονται ως σχετικές (π.χ. τα Προϊόντα εκκαθαρίζουν και Κατηγορίες και Ετικέτες). Αποεπιλέξτε το για στενότερη εκκαθάριση.
4. Πατήστε **Εκκαθάριση επιλεγμένων**.

Ένα πράσινο μήνυμα αναφέρει πόσα κλειδιά API και πόσα κλειδιά καταστήματος αφαιρέθηκαν. Κόκκινο μήνυμα σημαίνει ότι το backend της cache του API δεν απάντησε και τίποτα δεν αφαιρέθηκε· κίτρινο ότι το ηλεκτρονικό κατάστημα δεν ήταν προσβάσιμο.

### Προεπισκόπηση πριν την εκκαθάριση

Επιλέξτε τις επιφάνειες και πατήστε **Δοκιμαστική εκτέλεση**. Το μήνυμα δείχνει πόσα κλειδιά **θα** αφαιρούνταν και τίποτα δεν διαγράφεται. Οι ζωντανοί μετρητές ενημερώνονται καθώς επιλέγετε.

### Εκκαθάριση όλων

Το **Εκκαθάριση όλων** αφαιρεί κάθε επιφάνεια μαζί εκτός από όσες είναι σημειωμένες ως Βαρύ, μετά από ερώτηση επιβεβαίωσης. Είναι ασφαλές αλλά κάνει τα επόμενα αιτήματα προς το κατάστημα πιο αργά όσο ξαναχτίζονται οι σελίδες. Προτιμήστε στοχευμένη εκκαθάριση σε ώρες αιχμής.

## Καλό είναι να ξέρετε

- Η εκκαθάριση δεν αλλάζει δεδομένα. Αν η ίδια η αλλαγή είναι λάθος, η εκκαθάριση απλώς θα δείξει το λάθος πιο γρήγορα.
- Η εκκαθάριση δεν επηρεάζει την cache του browser του πελάτη ούτε ένα CDN μπροστά από τον ιστότοπο· ένας πελάτης ίσως χρειαστεί ανανέωση.
- Τα αποτελέσματα αναζήτησης έρχονται από το ευρετήριο της μηχανής αναζήτησης, όχι από αυτή την cache· ένα προϊόν που δεν εμφανίζεται στην αναζήτηση ευρετηριάζεται ξανά στην αποθήκευση και από νυχτερινή εργασία.
- Τα feeds προϊόντων για Meta και TikTok ανανεώνονται με εκκαθάριση Προϊόντων ή Κατηγοριών.
- Κάθε εκκαθάριση καταγράφεται· οι χειριστές πλατφόρμας βλέπουν το πλήρες αρχείο στο <span class="sidebar-path">Σύστημα → Καταχωρήσεις & Logs → Καταχωρήσεις Καθαρισμού Cache</span>.
- Πλήρης επαναφορά της cache τρέχει αυτόματα και την 1η κάθε μήνα στις 04:00.
