# Έλεγχος & αρχεία καταγραφής

<span class="sidebar-path">Σύστημα → Καταχωρήσεις & Logs</span>

**Μόνο για χειριστές πλατφόρμας.** Οι λίστες αυτές είναι ορατές στους υπερχρήστες της πλατφόρμας (`admin/mixins.py`, `IsSuperuserOnlyModelAdmin`). Είναι αρχεία μόνο για ανάγνωση: τίποτα δεν προστίθεται ούτε αλλάζει, και τα περισσότερα δεν διαγράφονται. Ένας Ιδιοκτήτης που χρειάζεται μια από αυτές τις απαντήσεις μπορεί να ζητήσει από την πλατφόρμα να κοιτάξει.

## Καταχωρήσεις Αποθέματος

Κάθε κίνηση αποθέματος κάθε προϊόντος, με το επίπεδο πριν και μετά (`order/models/stock_log.py`).

Στήλες: **Προϊόν**, **Τύπος λειτουργίας**, **Μεταβολή αποθέματος** (πριν → μετά, με τη διαφορά με πρόσημο), **Παραγγελία**, **Εκτελέστηκε από**, **Δημιουργήθηκε**. Φίλτρα: τύπος λειτουργίας, εύρος ημερομηνιών, κατηγορία προϊόντος. Εμβάθυνση ημερομηνίας πάνω από τον πίνακα. Αναζήτηση: όνομα προϊόντος, SKU, id παραγγελίας, αιτία.

| Λειτουργία | Σημασία |
|---|---|
| Δέσμευση | Απόθεμα που κρατήθηκε για checkout σε εξέλιξη. |
| Αποδέσμευση | Δέσμευση που επιστράφηκε (το checkout έληξε ή ακυρώθηκε). |
| Μείωση | Μόνιμη μείωση αποθέματος (επιβεβαίωση παραγγελίας). |
| Αύξηση | Απόθεμα που επιστράφηκε (ακύρωση ή επιστροφή παραγγελίας) ή χειροκίνητη αύξηση. |

Ερώτηση που απαντά: «γιατί το προϊόν δείχνει 3 σε απόθεμα ενώ μέτρησα 5;» Φιλτράρετε κατά προϊόν και διαβάστε την ακολουθία.

## Ιστορικό Παραγγελιών

Μία γραμμή ανά αλλαγή σε παραγγελία (`order/models/history.py`).

Στήλες: **Παραγγελία**, **Τύπος Αλλαγής**, **Περιγραφή**, **Άλλαξε από** (ένα άτομο ή «Σύστημα»), **Διεύθυνση IP**, **Δημιουργήθηκε**. Φίλτρα: τύπος αλλαγής, παραγγελία, χρήστης, εύρος ημερομηνιών.

Τύποι αλλαγής: Αλλαγή κατάστασης, Ενημέρωση πληρωμής, ενημέρωση αποστολής, ενημέρωση στοιχείων πελάτη, ενημέρωση ειδών, ενημέρωση διεύθυνσης, Σημείωση προστέθηκε, Επιστροφή ολοκληρώθηκε, άλλη αλλαγή. Η γραμμή κρατά την προηγούμενη και τη νέα τιμή.

Το ίδιο ιστορικό εμφανίζεται ενσωματωμένο στο κάτω μέρος κάθε παραγγελίας στις [Παραγγελίες](/el/admin/sales/orders)· αυτή η λίστα είναι η συνολική προβολή για όλες τις παραγγελίες.

## Ιστορικό Ειδών Παραγγελίας

Αλλαγές σε μεμονωμένες γραμμές παραγγελίας: αλλαγή ποσότητας, ενημέρωση τιμής, επιστροφή είδους, άλλη αλλαγή. Στήλες: **Είδος παραγγελίας** (με την παραγγελία του), **Τύπος Αλλαγής**, **Περιγραφή**, **Άλλαξε από**, **Δημιουργήθηκε**.

## Συμβάντα BoxNow

Κάθε παράδοση webhook από την BoxNow για ένα δέμα (`shipping_boxnow/models/parcel_event.py`). Στήλες: **Voucher**, **Τύπος συμβάντος**, **Κατάσταση Δέματος**, **Ώρα συμβάντος**, **Όνομα εμφάνισης** (το locker ή η εγκατάσταση), **Παραλήφθηκε στις**. Φίλτρα: τύπος συμβάντος, κατάσταση δέματος, ώρα συμβάντος. Αναζήτηση: id δέματος, id μηνύματος webhook. Το ακατέργαστο payload βρίσκεται σε διπλωμένο μπλοκ στη σελίδα λεπτομερειών.

Τα ίδια συμβάντα εμφανίζονται ενσωματωμένα σε κάθε αποστολή στο [BoxNow](/el/admin/shipping/boxnow). Χρησιμοποιήστε αυτή τη λίστα όταν ένας πελάτης ρωτά πού είναι το δέμα και η σελίδα της αποστολής δεν αρκεί.

## Συμβάντα Παρακολούθησης ACS

Κάθε σημείο ελέγχου που ανέφερε η ACS για ένα voucher (`shipping_acs/models/tracking_event.py`), από webhooks και από την εργασία που ρωτά κάθε δεκαπέντε λεπτά. Στήλες: **Αποστολή**, **Ώρα συμβάντος**, **Ενέργεια σημείου ελέγχου**, **Τοποθεσία σημείου ελέγχου**, **Παραλήφθηκε στις**. Φίλτρα: ενέργεια, ημερομηνία παραλαβής. Αναζήτηση: αριθμός voucher, ενέργεια, τοποθεσία. Ακατέργαστο payload στη σελίδα λεπτομερειών.

Τα ίδια συμβάντα εμφανίζονται ενσωματωμένα σε κάθε αποστολή στο [ACS Courier](/el/admin/shipping/acs), όπου εξηγούνται και οι καταστάσεις voucher που καθορίζουν.

## Συμβάντα Viva Webhook

Κάθε ειδοποίηση πληρωμής που έστειλε το Viva Wallet (`order/models/viva_webhook_event.py`). Στήλες: **Αναγνωριστικό συναλλαγής**, **Αναγνωριστικό τύπου συμβάντος**, **Έκβαση**, **Παραγγελία**, **Κωδικός παραγγελίας**, **Αναγνωριστικό κατάστασης**, **Παραλήφθηκε στις**.

| Τύπος συμβάντος | Σημασία |
|---|---|
| 1796 | Δημιουργία πληρωμής συναλλαγής (μια πληρωμή πέτυχε) |
| 1797 | Δημιουργία αντιστροφής συναλλαγής (επιστροφή χρημάτων ή αντιστροφή) |
| 1798 | Αποτυχία συναλλαγής |

| Έκβαση | Σημασία |
|---|---|
| Επεξεργάστηκε | Η παραγγελία ενημερώθηκε. |
| Παραλείφθηκε | Διπλή παράδοση, αγνοήθηκε σκόπιμα. |
| Απέτυχε | Ο χειριστής απέτυχε· η παραγγελία ίσως χρειάζεται χειροκίνητο έλεγχο. |

Ερώτηση που απαντά: «ο πελάτης λέει ότι πλήρωσε αλλά η παραγγελία είναι ακόμη εκκρεμής». Αναζητήστε το id παραγγελίας· αν δεν υπάρχει γραμμή, το Viva δεν παρέδωσε ποτέ το συμβάν, αν υπάρχει γραμμή με Απέτυχε, έφτασε αλλά δεν εφαρμόστηκε.

## Καταχωρήσεις Meta CAPI

Κάθε συμβάν που στάλθηκε από τον server στο Conversions API της Meta (`meta_capi/models.py`). Στήλες: **Όνομα συμβάντος**, **Κατάσταση** (Εκκρεμεί, Απεστάλη, Απέτυχε, Παραλείφθηκε), **Συμβάντα που παραλήφθηκαν** (ο μετρητής της Meta), **Παραγγελία**, **Χρήστης**, **fbtrace id**, **Δημιουργήθηκε**. Φίλτρα: κατάσταση, όνομα συμβάντος, ημερομηνία, με εμβάθυνση ημερομηνίας. Αναζήτηση: id συμβάντος, trace id, id παραγγελίας, email χρήστη.

Μια σειρά από Απέτυχε συνήθως σημαίνει ότι έληξε το access token στο προφίλ καταστήματος. Παραλείφθηκε σημαίνει ότι το συμβάν δεν στάλθηκε, συνήθως επειδή έλειπε η συγκατάθεση ή ο διακόπτης ήταν κλειστός. Δείτε `META_CAPI_ENABLED` στις [Ρυθμίσεις καταστήματος](/el/admin/settings/store-settings).

## Καταχωρήσεις Καθαρισμού Cache

Ποιος εκκαθάρισε ποιες επιφάνειες cache και τι έγινε (`core/cache/models.py`). Στήλες: **Δημιουργήθηκε**, **Actor**, **Επιφάνειες**, **Κλειδιά Django**, **Κλειδιά Nuxt**, **Μπλοκαρισμένα κλειδιά**, **Δοκιμαστική εκτέλεση**. Οι ίδιες είκοσι πιο πρόσφατες γραμμές εμφανίζονται και στη σελίδα [Cache](/el/admin/system/cache), την οποία μπορεί να ανοίξει κάθε χρήστης του διαχειριστικού.

## Εξαγωγές Δεδομένων Χρηστών

Αιτήματα εξαγωγής δεδομένων GDPR που έκαναν πελάτες από τον λογαριασμό τους στο ηλεκτρονικό κατάστημα (`user/models/data_export.py`). Μόνο ο πελάτης μπορεί να δημιουργήσει αίτημα· η λίστα είναι μόνο για ανάγνωση. Στήλες: **Χρήστης**, **Κατάσταση** (Εκκρεμεί, Σε επεξεργασία, Έτοιμο, Απέτυχε, Έληξε), **Μέγεθος αρχείου**, **Λήγει στις**, **Δημιουργήθηκε**. Ένα έτοιμο αρχείο κατεβαίνει από τον πελάτη για επτά ημέρες, μετά διαγράφεται από νυχτερινή εργασία. Δείτε [Εξαγωγές δεδομένων (GDPR)](/el/admin/customers/data-exports) για τη ροή από την πλευρά του πελάτη.

## Καλό είναι να ξέρετε

- Οι γραμμές γράφονται από το σύστημα τη στιγμή που συμβαίνουν τα πράγματα· μια γραμμή που λείπει είναι και αυτή πληροφορία (webhook που δεν έφτασε ποτέ, αλλαγή αποθέματος εκτός καταστήματος).
- Οι σελίδες παραγγελίας δείχνουν καρτέλες **Καταχωρήσεις Αποθέματος** και **Ιστορικό Παραγγελιών** μόνο σε χειριστές πλατφόρμας· το προσωπικό του καταστήματος βλέπει το ενσωματωμένο ιστορικό μέσα στην παραγγελία.
- Τίποτα σε αυτές τις λίστες δεν διαγράφεται αυτόματα εκτός από τις ληγμένες εξαγωγές δεδομένων.
