# Έλεγχος & αρχεία καταγραφής

<span class="sidebar-path">Σύστημα → Καταχωρήσεις & Logs</span>

**Μόνο για χειριστές πλατφόρμας.** Αυτές οι οκτώ λίστες αρνούνται να ανοίξουν για οποιονδήποτε άλλον, όποια διεύθυνση κι αν γραφτεί. Είναι αρχεία μόνο για ανάγνωση: τίποτα δεν προστίθεται, σχεδόν τίποτα δεν αλλάζει, και τις γραμμές τις γράφει το ίδιο το σύστημα καθώς συμβαίνουν τα πράγματα. Ένας Ιδιοκτήτης που χρειάζεται μια από αυτές τις απαντήσεις μπορεί να ζητήσει από την πλατφόρμα να κοιτάξει.

## Καταχωρήσεις Αποθέματος

Κάθε κίνηση αποθέματος κάθε προϊόντος, με το επίπεδο πριν και μετά.

Στήλες: **Προϊόν**, **Τύπος κίνησης**, **Μεταβολή Αποθέματος** (πριν → μετά, με τη διαφορά), **Παραγγελία**, **Από**, **Δημιουργήθηκε**. Φίλτρα: τύπος κίνησης, εύρος ημερομηνιών, κατηγορία προϊόντος. Εμβάθυνση ημερομηνίας πάνω από τον πίνακα. Αναζήτηση: όνομα προϊόντος, SKU, id παραγγελίας, αιτία.

| Κίνηση | Σημασία |
|---|---|
| **Δέσμευση** | Απόθεμα κρατημένο για checkout σε εξέλιξη. |
| **Αποδέσμευση** | Μια δέσμευση που επιστράφηκε (το checkout έληξε ή ακυρώθηκε). |
| **Μείωση** | Απόθεμα που αφαιρέθηκε οριστικά (επιβεβαίωση παραγγελίας). |
| **Αύξηση** | Απόθεμα που επέστρεψε (ακύρωση ή επιστροφή παραγγελίας) ή χειροκίνητη αύξηση. |

Σε τι απαντά: «γιατί το προϊόν δείχνει 3 τεμάχια ενώ μέτρησα 5;» Φιλτράρετε ανά προϊόν και διαβάστε τη σειρά των κινήσεων.

## Ιστορικό Παραγγελιών

Μία γραμμή ανά αλλαγή σε παραγγελία.

Στήλες: **Παραγγελία**, **Τύπος αλλαγής**, **Περιγραφή**, **Άλλαξε από** (άτομο ή «Σύστημα»), **Διεύθυνση IP**, **Δημιουργήθηκε**. Φίλτρα: τύπος αλλαγής, παραγγελία, χρήστης, εύρος ημερομηνιών. Αναζήτηση: id παραγγελίας, περιγραφή, email ή όνομα χρήστη, διεύθυνση IP.

Τύποι αλλαγής: Αλλαγή Κατάστασης, Ενημέρωση Πληρωμής, Ενημέρωση Αποστολής, Ενημέρωση Στοιχείων Πελάτη, Ενημέρωση Ειδών, Ενημέρωση Διεύθυνσης, Προσθήκη Σημείωσης, Επιστροφή Χρημάτων, Άλλη Αλλαγή. Η γραμμή κρατά την προηγούμενη και τη νέα τιμή.

Το ίδιο ιστορικό εμφανίζεται και στο κάτω μέρος κάθε παραγγελίας στις [Παραγγελίες](/el/admin/sales/orders)· αυτή η λίστα είναι η συνολική προβολή.

## Ιστορικό Ειδών Παραγγελίας

Αλλαγές σε μεμονωμένες γραμμές παραγγελίας: Αλλαγή Ποσότητας, Ενημέρωση Τιμής, Επιστροφή Είδους, Άλλη Αλλαγή. Στήλες: **Είδος Παραγγελίας** (με την παραγγελία του), **Τύπος αλλαγής**, **Περιγραφή**, **Άλλαξε από**, **Δημιουργήθηκε**. Η γραμμή κρατά την προηγούμενη και τη νέα τιμή.

## Συμβάντα BoxNow

Κάθε ειδοποίηση που έστειλε η BoxNow για ένα δέμα. Στήλες: **Voucher**, **Τύπος συμβάντος**, **Κατάσταση Δέματος**, **Ώρα συμβάντος**, **Όνομα εμφάνισης** (η θυρίδα ή η εγκατάσταση), **Παραλήφθηκε στις**. Φίλτρα: τύπος συμβάντος, κατάσταση δέματος, ώρα συμβάντος. Αναζήτηση: id δέματος, id μηνύματος. Το ακατέργαστο μήνυμα βρίσκεται σε διπλωμένο μπλοκ στη σελίδα λεπτομερειών.

Τα ίδια συμβάντα εμφανίζονται και σε κάθε αποστολή στο [BoxNow](/el/admin/shipping/boxnow). Χρησιμοποιήστε αυτή τη λίστα όταν ένας πελάτης ρωτά πού είναι το δέμα και η σελίδα της αποστολής δεν αρκεί.

## Συμβάντα Παρακολούθησης ACS

Κάθε σημείο ελέγχου που ανέφερε η ACS για ένα voucher. Στήλες: **Αποστολή**, **Ώρα συμβάντος**, **Ενέργεια σημείου ελέγχου**, **Τοποθεσία σημείου ελέγχου**, **Παραλήφθηκε στις**. Φίλτρα: ενέργεια, ημερομηνία παραλαβής. Αναζήτηση: αριθμός voucher, ενέργεια, τοποθεσία. Η ακατέργαστη εγγραφή είναι στη σελίδα λεπτομερειών.

**Η ACS δεν στέλνει τίποτα από μόνη της.** Σε αντίθεση με την BoxNow, δεν έχει καθόλου ειδοποιήσεις, οπότε κάθε γραμμή εδώ την έφερε η εργασία που ρωτά κάθε δεκαπέντε λεπτά ή κάποιος που πάτησε **Επανέλεγχος παρακολούθησης ACS**. Καθυστέρηση έως δεκαπέντε λεπτά είναι φυσιολογική.

Τα ίδια συμβάντα εμφανίζονται και σε κάθε αποστολή στο [ACS Courier](/el/admin/shipping/acs), που εξηγεί και τις καταστάσεις voucher στις οποίες οδηγούν.

## Συμβάντα Viva Webhook

Κάθε ειδοποίηση πληρωμής που έστειλε το Viva Wallet. Στήλες: **Αναγνωριστικό συναλλαγής**, **Αναγνωριστικό τύπου συμβάντος**, **Έκβαση**, **Παραγγελία**, **Κωδικός παραγγελίας**, **Αναγνωριστικό κατάστασης**, **Παραλήφθηκε στις**. Φίλτρα: τύπος συμβάντος, έκβαση, ημερομηνία παραλαβής. Αναζήτηση: id συναλλαγής, κωδικός παραγγελίας, id παραγγελίας.

| Τύπος συμβάντος | Σημασία |
|---|---|
| 1796 | Δημιουργήθηκε πληρωμή (η πληρωμή πέτυχε) |
| 1797 | Δημιουργήθηκε αντιστροφή (επιστροφή χρημάτων ή ακύρωση) |
| 1798 | Η συναλλαγή απέτυχε |

| Έκβαση | Σημασία |
|---|---|
| **Επεξεργάστηκε** | Η παραγγελία ενημερώθηκε. |
| **Παραλείφθηκε** | Διπλή παράδοση, αγνοήθηκε σκόπιμα. |
| **Απέτυχε** | Η επεξεργασία απέτυχε· η παραγγελία ίσως χρειάζεται χειροκίνητο έλεγχο. |

Σε τι απαντά: «ο πελάτης λέει ότι πλήρωσε αλλά η παραγγελία είναι ακόμη εκκρεμής». Αναζητήστε το id παραγγελίας. Καμία γραμμή σημαίνει ότι το Viva δεν έστειλε ποτέ το συμβάν· γραμμή με Απέτυχε σημαίνει ότι έφτασε αλλά δεν εφαρμόστηκε.

## Καταχωρήσεις Meta CAPI

Κάθε συμβάν που στάλθηκε από τον server στο Conversions API της Meta. Στήλες: **Όνομα συμβάντος**, **Κατάσταση** (Εκκρεμεί, Απεστάλη, Απέτυχε, Παραλείφθηκε), **Συμβάντα που παραλήφθηκαν** (ο μετρητής της Meta), **Παραγγελία**, **Χρήστης**, **fbtrace id**, **Δημιουργήθηκε**. Φίλτρα: κατάσταση, όνομα συμβάντος, ημερομηνία, με εμβάθυνση ημερομηνίας. Αναζήτηση: id συμβάντος, trace id, id παραγγελίας, email χρήστη.

Μια σειρά από γραμμές «Απέτυχε» σημαίνει συνήθως ότι έληξε το access token στο προφίλ του καταστήματος. «Παραλείφθηκε» σημαίνει ότι το συμβάν δεν στάλθηκε, συνήθως επειδή δεν υπήρχε συγκατάθεση ή ο διακόπτης ήταν κλειστός. Δείτε τη ρύθμιση `META_CAPI_ENABLED` στις [Ρυθμίσεις καταστήματος](/el/admin/settings/store-settings).

## Εξαγωγές Δεδομένων Χρηστών

Αιτήματα εξαγωγής δεδομένων που κάνουν πελάτες από τον λογαριασμό τους στο κατάστημα. Μόνο ο πελάτης μπορεί να δημιουργήσει αίτημα· η λίστα είναι μόνο για ανάγνωση. Στήλες: **Χρήστης**, **Κατάσταση** (Εκκρεμεί, Σε επεξεργασία, Έτοιμο, Απέτυχε, Έληξε), **Μέγεθος αρχείου**, **Λήγει στις**, **Δημιουργήθηκε**. Φίλτρα: κατάσταση, ημερομηνία δημιουργίας, ημερομηνία λήξης. Αναζήτηση: email και όνομα χρήστη, token. Ένα έτοιμο αρχείο κατεβαίνει από τον πελάτη για επτά ημέρες, μετά το διαγράφει νυχτερινή εργασία. Δείτε [Εξαγωγές δεδομένων (GDPR)](/el/admin/customers/data-exports) για τη ροή από την πλευρά του πελάτη.

## Καλό είναι να ξέρετε

- Μια γραμμή που λείπει είναι κι αυτή πληροφορία: μια ειδοποίηση που δεν έφτασε ποτέ, ή μια αλλαγή αποθέματος που έγινε εκτός καταστήματος.
- **Οι εκκαθαρίσεις cache δεν είναι εδώ.** Καταγράφεται ποιος καθάρισε τι, αλλά η καταγραφή αφορά όλη την πλατφόρμα — μία λίστα για όλα τα καταστήματα, με το όνομα όποιου έτρεξε κάθε εκκαθάριση — οπότε βρίσκεται στην κονσόλα της πλατφόρμας, και στη διεύθυνση ενός καταστήματος η λίστα αρνείται πλέον να ανοίξει, ακόμη και για χειριστές της πλατφόρμας. Οι είκοσι πιο πρόσφατες εκκαθαρίσεις που φαίνονται στο κάτω μέρος της σελίδας [Cache](/el/admin/system/cache) προέρχονται από την ίδια καταγραφή όλης της πλατφόρμας, οπότε δεν περιορίζονται στο δικό σας κατάστημα· ο ίδιος ο καθαρισμός δεν άλλαξε και μπορεί να τον κάνει κάθε χρήστης του διαχειριστικού.
- Οι σελίδες παραγγελιών δείχνουν καρτέλες **Καταχωρήσεις Αποθέματος** και **Ιστορικό Παραγγελιών** μόνο σε χειριστές πλατφόρμας· το προσωπικό του καταστήματος βλέπει το ιστορικό μέσα στην ίδια την παραγγελία.
- Τίποτα σε αυτές τις λίστες δεν διαγράφεται αυτόματα, εκτός από τις ληγμένες εξαγωγές δεδομένων.
