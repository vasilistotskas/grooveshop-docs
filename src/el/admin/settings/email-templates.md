# Πρότυπα email

Εδώ βλέπετε ακριβώς τι λαμβάνει ένας πελάτης σε κάθε αυτόματο email του καταστήματος: επιβεβαίωση παραγγελίας, αποστολή, ακύρωση κ.ά. Η σελίδα είναι μόνο για προεπισκόπηση. Τα κείμενα των email τα γράφει η πλατφόρμα, και από εδώ δεν αλλάζουν ούτε στέλνονται.

<span class="sidebar-path">Ρυθμίσεις → Πρότυπα Email</span>

Η σελίδα εμφανίζεται μόνο σε όσους μπορούν να βλέπουν παραγγελίες, γιατί δείχνει πραγματικές παραγγελίες πελατών.

## Τι βλέπετε

Η σελίδα **Διαχείριση Προτύπων Email** έχει δύο μέρη:

- **Πρότυπα**, αριστερά: η λίστα με όλα τα email, χωρισμένη σε κατηγορίες. Κάθε email έχει το όνομά του στα αγγλικά, την ένδειξη **Ενεργή** και μια σύντομη περιγραφή. Η **Αναζήτηση προτύπων...** φιλτράρει τη λίστα καθώς γράφετε.
- **Προεπισκόπηση**, δεξιά: το email που διαλέξατε, με το θέμα του από πάνω. Με μια από τις παραγγελίες σας, το θέμα είναι αυτό που έλαβε (ή θα λάμβανε) ο πελάτης της παραγγελίας. Με δείγμα δεδομένων θέμα δείχνουν μόνο τα email παραγγελιών· τα υπόλοιπα δεν δείχνουν θέμα.

Πάνω από την προεπισκόπηση διαλέγετε:

| Επιλογή | Τι αλλάζει |
|---|---|
| **Γλώσσα** | Η γλώσσα του email: ελληνικά ή αγγλικά. |
| **Δεδομένα** | **Δείγμα δεδομένων** (φανταστικός πελάτης και προϊόντα) ή μία από τις 10 πιο πρόσφατες παραγγελίες σας. |
| **Μορφή** | **HTML** (όπως το βλέπει ο πελάτης) ή **Κείμενο** (η απλή εκδοχή, για προγράμματα email χωρίς εικόνες). |

### Ποια email υπάρχουν

Τα ονόματα και οι κατηγορίες εμφανίζονται στα αγγλικά.

| Στην οθόνη | Τι είναι |
|---|---|
| `order_received` | Η παραγγελία καταχωρήθηκε. |
| `order_payment_confirmed` | Η πληρωμή επιβεβαιώθηκε. |
| `payment_failed` | Η πληρωμή απέτυχε. |
| `order_shipped` | Η παραγγελία στάλθηκε. |
| `acs_out_for_delivery` | Η ACS βγήκε για παράδοση. |
| `boxnow_parcel_at_locker` | Το δέμα είναι στο locker (θυρίδα) της BoxNow. |
| `order_delivered`, `order_completed` | Η παραγγελία παραδόθηκε / ολοκληρώθηκε. Με ενεργές τις κριτικές προϊόντων, κάθε email έχει έναν σύνδεσμο «Γράψτε κριτική» ανά προϊόν. Όταν απαιτείται αγορά για να γράψει κάποιος κριτική, οι παραγγελίες χωρίς λογαριασμό δεν παίρνουν σύνδεσμο. |
| `order_canceled` | Η παραγγελία ακυρώθηκε. |
| `order_refunded`, `order_returned` | Επιστροφή χρημάτων / επιστροφή προϊόντων. |
| `order_status_generic` | Κάθε άλλη αλλαγή κατάστασης. |
| `retail_document_issued` | Εκδόθηκε η απόδειξη ή το πιστωτικό παραστατικό. |
| `dispute_notification` | Αμφισβήτηση πληρωμής, προς εσάς. |
| `admin_new_order` | Νέα παραγγελία, προς εσάς. |
| `contact_notification` | Μήνυμα από τη φόρμα επικοινωνίας σας, προς εσάς. |
| `feedback_notification` | Σχόλια που άφησε επισκέπτης για το κατάστημα, προς εσάς. |
| `checkout_abandoned` | Υπενθύμιση για ταμείο που έμεινε στη μέση. |
| `restock_alert`, `price_drop_alert` | Οι [ειδοποιήσεις προϊόντων](/el/admin/customers/product-alerts). |
| `low_stock_alert` | Χαμηλό απόθεμα, προς εσάς. |
| `review_pending` | Νέα κριτική περιμένει έλεγχο, προς εσάς. |
| `gift_card_delivery`, `gift_card_purchase_receipt`, `gift_card_expiry_reminder` | Παράδοση δωροκάρτας, απόδειξη αγοράς της, υπενθύμιση λήξης. |
| `business_profile_approved`, `business_profile_rejected` | Έγκριση ή απόρριψη αίτησης εταιρικού πελάτη. |
| `admin_new_business_profile` | Νέα αίτηση εταιρικού πελάτη, προς εσάς. |
| `stale_shipments_alert` | Αποστολές ACS που έχουν κολλήσει, προς εσάς. |
| `confirmation` | Επιβεβαίωση συνδρομής newsletter. |
| `data_export_ready` | Η εξαγωγή δεδομένων του πελάτη είναι έτοιμη. |
| `inactive_user_email_template` | Μήνυμα σε πελάτη που έχει καιρό να μπει. |
| `email_confirmation`, `login_code` | Επιβεβαίωση διεύθυνσης email και κωδικός σύνδεσης. |
| `password_reset_key`, `password_reset_code`, `password_reset` | Σύνδεσμος επαναφοράς, κωδικός επαναφοράς και ειδοποίηση ότι έγινε επαναφορά του κωδικού. |
| `password_changed`, `password_set`, `email_changed`, `email_deleted` | Ειδοποιήσεις ασφαλείας: άλλαξε ο κωδικός ή η διεύθυνση email, ορίστηκε κωδικός, αφαιρέθηκε διεύθυνση. |
| `unknown_account`, `account_already_exists` | Κάποιος συνδέθηκε με διεύθυνση χωρίς λογαριασμό, ή έκανε εγγραφή με διεύθυνση που έχει ήδη λογαριασμό. |
| `totp_activated`, `totp_deactivated`, `recovery_codes_generated`, `webauthn_added`, `webauthn_removed` | Ειδοποιήσεις ασφαλείας για τη διπλή επαλήθευση: εφαρμογή ταυτοποίησης, κωδικοί ανάκτησης, κλειδιά ασφαλείας. |
| `account_connected`, `account_disconnected` | Συνδέθηκε ή αποσυνδέθηκε σύνδεση μέσω τρίτου (Google, Facebook κ.ά.). |
| `expiring`, `expired`, `suspended` | Ειδοποιήσεις της πλατφόρμας προς εσάς για τη συνδρομή του καταστήματος. |

Μερικά email έχουν δική τους περιγραφή. Τα υπόλοιπα γράφουν απλώς «Email template». Αυτό δεν σημαίνει ότι δεν στέλνονται.

Τα email που λαμβάνει ο πελάτης για τον λογαριασμό του (κωδικός σύνδεσης, επιβεβαίωση διεύθυνσης email, επαναφορά κωδικού, ειδοποιήσεις ασφαλείας) βρίσκονται στις κατηγορίες **Ασφάλεια λογαριασμού**, **Διπλή επαλήθευση** και **Σύνδεση μέσω τρίτων**. Φέρουν το όνομα και το λογότυπο του καταστήματός σας, στη γλώσσα του πελάτη. Προστατεύουν τον λογαριασμό του πελάτη, οπότε δεν απενεργοποιούνται: στη σελίδα <span class="sidebar-path">Ρυθμίσεις → Email</span> εμφανίζονται ως υποχρεωτικά.

## Εργασίες

### Δείτε τι θα λάβει ένας πελάτης

1. Ανοίξτε <span class="sidebar-path">Ρυθμίσεις → Πρότυπα Email</span>.
2. Πατήστε το email, π.χ. `order_shipped`.
3. Στη **Γλώσσα**, διαλέξτε τη γλώσσα του πελάτη.
4. Στα **Δεδομένα**, διαλέξτε την παραγγελία του.
5. Αλλάξτε **Μορφή** για να δείτε και την απλή εκδοχή.

Τίποτα δεν στέλνεται και τίποτα δεν αλλάζει στην παραγγελία.

### Ελέγξτε τις μεταφράσεις

Ανοίξτε το ίδιο email σε κάθε γλώσσα του καταστήματος και διαβάστε το. Αν κάτι λείπει ή είναι λάθος, στείλτε στην ομάδα της πλατφόρμας το όνομα του email, τη γλώσσα και τι θέλετε να αλλάξει.

## Καλό είναι να ξέρετε

- **Δεν αλλάζετε τα κείμενα από εδώ.** Μια αλλαγή σε email είναι αίτημα προς την ομάδα της πλατφόρμας. Δείτε [Πότε καλώ την υποστήριξη](/el/admin/help/contact-support).
- **Μόνο οι 10 πιο πρόσφατες παραγγελίες** εμφανίζονται στα **Δεδομένα**. Μια παλιότερη παραγγελία δεν μπορείτε να τη δείτε εδώ.
- **Τα email πελατών** φεύγουν στη γλώσσα του πελάτη.
- **Τα email υπενθύμισης και «Μας λείπετε!» έχουν σύνδεσμο απεγγραφής.** Ο πελάτης που τον πατά (ή πατά το κουμπί **Απεγγραφή** του προγράμματος email του) δεν παίρνει ξανά `checkout_abandoned` ούτε `inactive_user_email_template`. Δείτε [Συνδρομές newsletter](/el/admin/customers/subscriptions).
- **Τα email προς εσάς** πηγαίνουν στο email επικοινωνίας του καταστήματος, που ορίζετε στο <span class="sidebar-path">Ρυθμίσεις → Προφίλ καταστήματος</span>. Οι ειδοποιήσεις για νέες κριτικές και για αποστολές που έχουν κολλήσει πηγαίνουν και στο email του ιδιοκτήτη. Οι ειδοποιήσεις για τη συνδρομή (`expiring`, `expired`, `suspended`) πηγαίνουν μόνο στο email του ιδιοκτήτη, που το ορίζει η ομάδα της πλατφόρμας. Τα email προς εσάς (νέα παραγγελία, αίτηση εταιρικού λογαριασμού, αμφισβήτηση πληρωμής, χαμηλό απόθεμα, αποστολές ACS που κόλλησαν, νέα κριτική, μήνυμα φόρμας επικοινωνίας, σχόλια) γράφονται στην προεπιλεγμένη γλώσσα του καταστήματος, μαζί με το θέμα. Τα email της φόρμας επικοινωνίας και των σχολίων έχουν ως διεύθυνση απάντησης το email του πελάτη, οπότε με το **Απάντηση** απαντάτε στον πελάτη. Τα email προς τους πελάτες είναι στη γλώσσα του πελάτη, και στην προεπιλεγμένη γλώσσα του καταστήματος για επισκέπτη ή λογαριασμό χωρίς δηλωμένη γλώσσα.
