# Ετικέτες

<span class="sidebar-path">Κατάλογος → Ετικέτες</span>

Οι ετικέτες είναι σύντομες μεταφραζόμενες σημάνσεις που προσαρτώνται σε προϊόντα από τη σελίδα του προϊόντος. Είναι ένας ελαφρύς τρόπος να σημειώνετε είδη για εσωτερική ομαδοποίηση ή καμπάνιες. Τα άρθρα του blog έχουν δικές τους ξεχωριστές ετικέτες· βλ. [Κατηγορίες, συντάκτες & ετικέτες](/el/admin/blog/categories-authors-tags).

## Τι βλέπετε

50 ετικέτες ανά σελίδα, με σειρά ταξινόμησης.

| Στήλη | Σημασία |
|---|---|
| **Όνομα** | Η μεταφρασμένη ετικέτα. |
| **Ενεργή** | Επεξεργάσιμο απευθείας στη λίστα· τσεκάρετε και πατήστε **Αποθήκευση** στο κάτω μέρος. |
| **Χρήση** | Πλήθος ειδών με την ετικέτα. |
| **Σειρά ταξινόμησης** | Σύρετε γραμμές για αλλαγή σειράς. |
| **Δημιουργήθηκε** | Χρονοσφραγίδα. |

Η **αναζήτηση** ψάχνει σε κείμενο ετικέτας και id. **Φίλτρα**: **Κατάσταση ετικέτας** (ενεργές, ανενεργές, σε χρήση, αχρησιμοποίητες, δημοφιλείς με πάνω από 10 χρήσεις, δημιουργημένες τις τελευταίες 7 ημέρες), **Εύρος χρήσης**, **Τύπος Περιεχομένου** (σε τι είδος αντικειμένου είναι προσαρτημένη), Ενεργή, εύρη ημερομηνιών.

**Μαζικές ενέργειες**:

| Ενέργεια | Αποτέλεσμα |
|---|---|
| **Ενεργοποίηση επιλεγμένων ετικετών** | Ενεργοποιεί. |
| **Απενεργοποίηση επιλεγμένων ετικετών** | Απενεργοποιεί. |
| **Ενημέρωση σειράς** | Αναριθμεί τις επιλεγμένες ετικέτες κατά χρήση, οι πιο χρησιμοποιημένες πρώτα, μετά κατά ετικέτα. |
| **Ανάλυση χρήσης ετικετών** | Δείχνει μήνυμα με σύνολο, ενεργές και σε χρήση για την επιλογή. |

Η φόρμα ετικέτας έχει **Πληροφορίες ετικέτας** (**Ετικέτα** ανά γλώσσα, **Ενεργή**), **Οργάνωση** (**Σειρά ταξινόμησης**) και συμπτυγμένες **Πληροφορίες συστήματος**.

## Εργασίες

### Δημιουργία ετικέτας και προσάρτηση σε προϊόντα
1. Πατήστε **Προσθήκη**, γράψτε την ελληνική **Ετικέτα** και τις άλλες γλώσσες, αποθηκεύστε.
2. Ανοίξτε κάθε προϊόν από τα [Προϊόντα](/el/admin/catalog/products), πηγαίνετε στην καρτέλα **Ετικέτες**, προσθέστε γραμμή, επιλέξτε την ετικέτα με αυτόματη συμπλήρωση, αποθηκεύστε.

### Συγχώνευση δύο ετικετών
Δεν υπάρχει ως ενέργεια. Για συγχώνευση, ανοίξτε τα προϊόντα που έχουν την ετικέτα που θέλετε να καταργήσετε (φιλτράρετε κατά **Τύπο Περιεχομένου** και ελέγξτε τη **Χρήση**, ή χρησιμοποιήστε την αυτόματη συμπλήρωση σε κάθε προϊόν), προσαρτήστε την ετικέτα που μένει και μετά διαγράψτε την παλιά. Η διαγραφή ετικέτας την αφαιρεί από κάθε είδος.

### Απόσυρση ετικέτας
Απενεργοποιήστε το **Ενεργή**. Οι αναθέσεις μένουν, ώστε να την ενεργοποιήσετε ξανά αργότερα.

## Καλό είναι να ξέρετε

- **Οι ετικέτες δεν εμφανίζονται στη σελίδα προϊόντος του καταστήματος**, και η λίστα προϊόντων δεν φιλτράρει με αυτές. Εκτίθενται μέσω του API και κατά τα άλλα είναι σήμερα εργαλείο εσωτερικής οργάνωσης.
- Μόνο τα προϊόντα χρησιμοποιούν αυτές τις ετικέτες. Το blog έχει δικό του μοντέλο ετικετών με δική του λίστα.
- Η ετικέτα είναι ανά γλώσσα· κατάστημα και admin πέφτουν σε όποια γλώσσα υπάρχει όταν η τρέχουσα είναι κενή.
- Η σειρά ταξινόμησης είναι ενιαία για όλες τις ετικέτες.
