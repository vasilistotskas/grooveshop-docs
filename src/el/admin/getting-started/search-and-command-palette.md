# Αναζήτηση & παλέτα εντολών

Το διαχειριστικό προσφέρει τέσσερις τρόπους να βρείτε κάτι: την παλέτα εντολών, το φίλτρο του πλευρικού μενού, το πεδίο αναζήτησης κάθε λίστας και το πλαίσιο φίλτρων. Η σελίδα εξηγεί τι ψάχνει πραγματικά το καθένα.

## Παλέτα εντολών

Πατήστε **Ctrl+K** (Windows, Linux) ή **⌘K** (macOS) οπουδήποτε μέσα στο διαχειριστικό.

- Πληκτρολογήστε μέρος ενός ονόματος, ένα email, έναν αριθμό παραγγελίας, ένα SKU ή έναν αριθμό voucher. Η παλέτα ψάχνει **σε κάθε μοντέλο που είναι καταχωρημένο στο διαχειριστικό του καταστήματός σας** ταυτόχρονα, με τα ίδια πεδία που χρησιμοποιεί το πεδίο αναζήτησης κάθε λίστας (`UNFOLD["COMMAND"]` στο `settings.py`, `core/utils/admin.py`).
- Τα αποτελέσματα ομαδοποιούνται ανά μοντέλο. Επιλέξτε με τα βελάκια και **Enter** για να ανοίξει η σελίδα επεξεργασίας.
- Η παλέτα κρατά και **ιστορικό** των εγγραφών που ανοίξατε πρόσφατα, το οποίο εμφανίζεται πριν πληκτρολογήσετε.
- Το **Enter** χωρίς αποτελέσματα δεν κάνει τίποτα (ένα script προστασίας αποτρέπει σφάλμα της παλέτας).

Παραδείγματα που λειτουργούν: το email ενός πελάτη, το όνομα προϊόντος σε οποιαδήποτε γλώσσα, ένα id παραγγελίας, ένας αριθμός voucher ACS, ένα id δέματος BoxNow, μια συμμετοχή μέσω email.

## Φίλτρο πλευρικού μενού

Το πεδίο πάνω από τις ενότητες του μενού περιορίζει τις καταχωρήσεις καθώς πληκτρολογείτε. Ταιριάζει μόνο τίτλους ενοτήτων και καταχωρήσεων· δεν ψάχνει εγγραφές.

## Πεδίο αναζήτησης λίστας

Κάθε λίστα έχει πεδίο αναζήτησης στην κορυφή. Ψάχνει τα πεδία που έχουν οριστεί για τη λίστα, για παράδειγμα:

| Λίστα | Ψάχνει |
|---|---|
| Παραγγελίες | id παραγγελίας, email και όνομα πελάτη, και άλλα |
| Προϊόντα | όνομα σε κάθε γλώσσα, SKU |
| Χρήστες | email, όνομα χρήστη, ονοματεπώνυμο |
| Καταχωρήσεις Αποθέματος | όνομα προϊόντος, SKU, id παραγγελίας, αιτία |
| Πρόσθετες Ρυθμίσεις | όνομα και περιγραφή ρύθμισης |

Τα ακριβή πεδία κάθε λίστας περιγράφονται στη σελίδα της στον οδηγό. Η αναζήτηση δεν διακρίνει πεζά και κεφαλαία και ταιριάζει τμήματα λέξεων.

## Φίλτρα

Το πλαίσιο φίλτρων στα δεξιά περιορίζει τη λίστα κατά κατάσταση, ημερομηνίες, σχετιζόμενες εγγραφές και άλλα κριτήρια. Δύο συμπεριφορές που αξίζει να ξέρετε:

- Οι περισσότερες λίστες εφαρμόζουν το φίλτρο μόλις το επιλέξετε. Στις **Πρόσθετες Ρυθμίσεις** το πλαίσιο έχει κουμπί υποβολής· επιλέξτε πολλά φίλτρα και εφαρμόστε τα μαζί.
- Τα φίλτρα εύρους ημερομηνιών δέχονται «από» και «έως». Λίστες με ιεραρχία ημερομηνίας (Καταχωρήσεις Αποθέματος, Καταχωρήσεις Meta CAPI) δείχνουν επιπλέον πάνω από τον πίνακα εμβάθυνση σε έτος, μήνα, ημέρα.

Τα φίλτρα αποτυπώνονται στη διεύθυνση URL. Αποθηκεύστε ως σελιδοδείκτη μια φιλτραρισμένη διεύθυνση για να επιστρέφετε στην ίδια προβολή, π.χ. τις εκκρεμείς παραγγελίες στις οποίες οδηγεί ο πίνακας ελέγχου.

## Ταξινόμηση

Κάντε κλικ στην κεφαλίδα μιας στήλης για ταξινόμηση· ξανά κλικ για αντίστροφη σειρά. Κρατήστε την ταξινόμηση και κάντε κλικ σε άλλη κεφαλίδα για ταξινόμηση κατά περισσότερες στήλες. Και η ταξινόμηση είναι μέρος της διεύθυνσης, οπότε ένας σελιδοδείκτης την κρατά. Δεν υπάρχει αποθηκευμένη ταξινόμηση ανά χρήστη πέρα από αυτό.

## Καρτέλες ανάμεσα σε σχετικές λίστες

Ορισμένες λίστες δείχνουν μια σειρά καρτελών στην κορυφή για να μεταβαίνετε ανάμεσα σε σχετικές οθόνες χωρίς το μενού: Παραγγελίες, Τιμολόγια (και, για χειριστές πλατφόρμας, Καταχωρήσεις Αποθέματος και Ιστορικό Παραγγελιών)· Αποστολές BoxNow, Lockers, Συμβάντα· Αποστολές ACS, Καταστήματα, Λίστες Παραλαβής, Αποδόσεις COD, Συμβάντα Παρακολούθησης· Χαρακτηριστικά, Τιμές Χαρακτηριστικών, Ομάδες παραλλαγών· Άρθρα Blog, Κατηγορίες, Συντάκτες, Σχόλια, Ετικέτες.

## Καλό είναι να ξέρετε

- Η παλέτα σέβεται τα δικαιώματα: ένα μέλος Προσωπικού δεν παίρνει αποτελέσματα από μοντέλα που δεν μπορεί να ανοίξει.
- Η αναζήτηση σε μεταφρασμένο πεδίο (όνομα προϊόντος, όνομα κατηγορίας) βρίσκει την εγγραφή σε όποια γλώσσα κι αν καταχωρήθηκε το κείμενο.
