# Πίνακας ελέγχου

<span class="sidebar-path">Πίνακας Ελέγχου</span>

Η πρώτη σελίδα μετά τη σύνδεση. Δείχνει πώς πήγε το κατάστημα σε μια περίοδο και τι περιμένει κάποιον να το χειριστεί. Μια ενότητα για λειτουργία που δεν έχετε, ή για σελίδα που ο ρόλος σας δεν ανοίγει, δεν εμφανίζεται.

## Τι βλέπετε

### Πάνω μέρος

Ένας χαιρετισμός με το όνομά σας και η σημερινή ημερομηνία. Δεξιά διαλέγετε περίοδο: **7 ημέρες**, **30 ημέρες** (η αρχική επιλογή), **13 εβδομάδες** ή **12 μήνες**. Το κουμπί **Νέο προϊόν** ανοίγει κενή φόρμα προϊόντος.

Κάθε περίοδος τελειώνει σήμερα και συγκρίνεται με την ίδια διάρκεια ακριβώς πριν. Για παράδειγμα, οι **7 ημέρες** είναι σήμερα και οι έξι προηγούμενες μέρες.

### Ειδοποιήσεις

Εμφανίζονται κάτω από τον χαιρετισμό, μόνο όταν κάτι χρειάζεται διόρθωση:

- **Οι νομικές σελίδες σας χρειάζονται ενημέρωση**: η πλατφόρμα πρόσθεσε κείμενο στα νομικά της έγγραφα. Οι σελίδες σας δεν άλλαξαν μόνες τους, γιατί το κείμενο είναι δικό σας. Ανοίξτε καθεμία για να δείτε τι πρέπει να προσθέσετε.
- **Λείπουν νομικά στοιχεία της επιχείρησής σας**: ο νόμος θέλει να φαίνεται στο κατάστημα ποιος πουλά. Η ειδοποίηση λέει τι λείπει και έχει σύνδεσμο **Συμπλήρωση στοιχείων**.
- **Λείπουν στοιχεία για την έκδοση αποδείξεων**: μόνο όταν το myDATA είναι ενεργό. Χωρίς επωνυμία, ΑΦΜ και ΔΟΥ, οι αποδείξεις δεν φτάνουν στην ΑΑΔΕ.

Τις δύο τελευταίες τις βλέπουν ο Ιδιοκτήτης και ο Διαχειριστής. Μόλις συμπληρώσετε τα στοιχεία, η ειδοποίηση φεύγει.

### Βασικά νούμερα

Τέσσερις κάρτες για την περίοδο. Η καθεμία δείχνει την αλλαγή σε σχέση με την προηγούμενη περίοδο και μια μικρή γραμμή με την πορεία της.

| Κάρτα | Τι μετράει |
|---|---|
| **Έσοδα** | Τα χρήματα από πληρωμένες παραγγελίες της περιόδου. |
| **Παραγγελίες** | Όλες οι παραγγελίες της περιόδου, σε όποια κατάσταση κι αν είναι. |
| **Μέση παραγγελία** | Τα έσοδα διά τις πληρωμένες παραγγελίες. Δείχνει **—** αν δεν πληρώθηκε καμία. |
| **Νέοι πελάτες** | Νέοι λογαριασμοί πελατών. Από κάτω, πόσοι από τους πελάτες που πλήρωσαν παρήγγειλαν ξανά. |

### Γράφημα πωλήσεων

Μία μπάρα ανά μέρα, εβδομάδα ή μήνα, ανάλογα με την περίοδο. Πάνω στο γράφημα διαλέγετε **Έσοδα** ή **Παραγγελίες**.

### Χρειάζονται προσοχή

Η δουλειά που περιμένει. Κάθε γραμμή ανοίγει τη λίστα ήδη φιλτραρισμένη σε αυτές τις εγγραφές. Όταν δεν περιμένει τίποτα, γράφει **Όλα έτοιμα: τίποτα δεν περιμένει.**

| Γραμμή | Τι μετράει |
|---|---|
| **Παραγγελίες προς επεξεργασία** | Παραγγελίες σε **Εκκρεμεί**. |
| **Παραγγελίες προς παρακολούθηση** | Πελάτες που περιμένουν ακόμη το δέμα τους πάνω από `ORDER_FOLLOW_UP_DAYS` μέρες. |
| **Ακυρωμένες παραγγελίες προς επιστροφή χρημάτων** | Πληρώθηκαν και ακυρώθηκαν, και ο πελάτης δεν έχει πάρει πίσω τα χρήματα. |
| **Αντικαταβολές που η ACS δεν έχει αποδώσει** | Δέματα με αντικαταβολή που παραδόθηκαν πριν από πάνω από 10 μέρες χωρίς απόδοση από την ACS. |
| **Καθυστερημένες αποστολές ACS** | Δέματα χωρίς κίνηση για τρεις μέρες, ή παραγγελίες χωρίς voucher (ετικέτα αποστολής) μία μέρα μετά. |
| **Χαμηλό απόθεμα** | Ενεργά προϊόντα με απόθεμα από 1 έως 9. |
| **Αποδείξεις που απέρριψε το myDATA** | Αποδείξεις που πρέπει να διορθωθούν και να σταλούν ξανά. |
| **Κριτικές προς έγκριση** | Κριτικές που οι πελάτες δεν βλέπουν ακόμη. |
| **Σχόλια blog προς έγκριση** | Σχόλια που οι αναγνώστες δεν βλέπουν ακόμη. |
| **Νέα μηνύματα** | Μηνύματα της φόρμας επικοινωνίας των τελευταίων 7 ημερών. |
| **Επαγγελματικοί λογαριασμοί προς έλεγχο** | Αιτήσεις εταιρικών πελατών που περιμένουν έλεγχο. |

Μια γραμμή εμφανίζεται μόνο όταν έχει κάτι να μετρήσει και μπορείτε να ανοίξετε τη λίστα της.

### Οι υπόλοιπες κάρτες

- **Πρόσφατες παραγγελίες**: οι έξι πιο πρόσφατες, ανεξάρτητα από την περίοδο.
- **Δημοφιλέστερα προϊόντα**: τα πέντε προϊόντα με τα περισσότερα πληρωμένα τεμάχια, μείον όσα επιστράφηκαν.
- **Πορεία ολοκλήρωσης αγοράς**: πόσα καλάθια ξεκίνησαν, πόσα έγιναν παραγγελία και πόσα πληρώθηκαν.
- **Από πού έρχονται οι παραγγελίες**: οι πέντε μεγαλύτερες πηγές παραγγελιών και οι υπόλοιπες μαζί ως **Άλλο**. Δείτε [Πηγή παραγγελίας](/el/admin/sales/order-source).
- **Αναζήτηση καταστήματος**: πόσες αναζητήσεις έγιναν, πόσες δεν βρήκαν τίποτα, και οι λίστες **Χωρίς αποτελέσματα** και **Κορυφαίες αναζητήσεις**.

## Εργασίες

### Δείτε άλλη περίοδο

Πατήστε **7 ημέρες**, **30 ημέρες**, **13 εβδομάδες** ή **12 μήνες**. Αλλάζουν όλα τα νούμερα της περιόδου. Οι **Πρόσφατες παραγγελίες** και τα **Χρειάζονται προσοχή** μένουν ίδια.

### Τακτοποιήστε ό,τι περιμένει

Πατήστε μια γραμμή στα **Χρειάζονται προσοχή**. Μόλις τακτοποιήσετε τις εγγραφές, η γραμμή φεύγει.

### Βελτιώστε την αναζήτηση

Δείτε τη λίστα **Χωρίς αποτελέσματα**. Για κάθε λέξη που ψάχνουν οι πελάτες χωρίς αποτέλεσμα, προσθέστε το προϊόν που ζητούν, ή γράψτε τη λέξη στο όνομα του σωστού προϊόντος.

## Καλό είναι να ξέρετε

- Τα έσοδα μετρούν μόνο πληρωμένες παραγγελίες, στη μέρα που έγινε η καθεμία. Μια παραγγελία με αντικαταβολή μετράει όταν πληρωθεί η αντικαταβολή, μέρες μετά την παράδοση. Έτσι οι πρόσφατες μέρες μπορεί να μεγαλώσουν αργότερα.
- Τα νούμερα ενημερώνονται μέσα σε λίγα λεπτά.
- Οι παραγγελίες επισκεπτών (χωρίς λογαριασμό) δεν μετρούν στους πελάτες που παρήγγειλαν ξανά.
