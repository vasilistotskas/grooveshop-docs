# Συστάσεις

<span class="sidebar-path">Marketing → Συστάσεις → Θέσεις</span>

Οι συστάσεις είναι μια λωρίδα με προτεινόμενα προϊόντα: στη σελίδα προϊόντος, στη σελίδα ενός εξαντλημένου προϊόντος και στο καλάθι. Το κατάστημα τις διαλέγει μόνο του, αλλά ό,τι ορίσετε εσείς στο προϊόν μπαίνει πάντα πρώτο.

## Τι βλέπετε

Κάθε **θέση** είναι ένα σημείο του καταστήματος όπου μπορεί να εμφανιστεί η λωρίδα.

| Στήλη | Τι δείχνει |
|---|---|
| **Επιφάνεια** | Το σημείο: **Σελίδα προϊόντος**, **Εξαντλημένο**, **Καλάθι**, **Άδειο καλάθι**, **Email παραγγελίας**. |
| **Ενεργοποιημένο** | Αν η λωρίδα εμφανίζεται σε αυτό το σημείο. |
| **Αλυσίδα** | Με ποια σειρά αναζητούνται προτάσεις (δείτε τον πίνακα πιο κάτω). |
| **Όριο** | Πόσα προϊόντα το πολύ δείχνει η λωρίδα. |
| **Ελάχιστη πλήρωση** | Αν βρεθούν λιγότερα από αυτά, η λωρίδα δεν εμφανίζεται καθόλου. |
| **Λόγος εύρους τιμής** | Π.χ. 3: δεν προτείνονται προϊόντα πάνω από τρεις φορές ακριβότερα ή φθηνότερα. Κενό = χωρίς όριο. |

Το κατάστημα σήμερα δείχνει λωρίδα μόνο στη **Σελίδα προϊόντος**, στο **Εξαντλημένο** και στο **Καλάθι**. Οι θέσεις **Άδειο καλάθι** και **Email παραγγελίας** υπάρχουν στη λίστα, αλλά δεν εμφανίζονται ακόμη πουθενά.

### Η αλυσίδα

Η **Αλυσίδα στρατηγικών** είναι μια λίστα με κωδικούς. Κάθε κωδικός συμπληρώνει τις θέσεις που έμειναν κενές, με τη σειρά.

| Κωδικός | Τι προτείνει |
|---|---|
| `curated` | Τα προϊόντα που ορίσατε εσείς στο προϊόν. Μπαίνουν πάντα πρώτα. |
| `variant_group` | Άλλες παραλλαγές του ίδιου προϊόντος (π.χ. άλλο χρώμα). |
| `category` | Προϊόντα της ίδιας ή συγγενικής κατηγορίας. |
| `popular` | Ένα δημοφιλές προϊόν του καταστήματος, το πολύ ένα ανά λωρίδα. |

Οι υπόλοιποι κωδικοί που μπορεί να δείτε στις αρχικές ρυθμίσεις (`attributes`, `semantic`, `co_purchase`, `co_view`) δεν προτείνουν τίποτα ακόμη και απλώς παραλείπονται.

## Εργασίες

### Ενεργοποίηση των συστάσεων

1. Ζητήστε από την ομάδα της πλατφόρμας να επιβεβαιώσει ότι οι συστάσεις περιλαμβάνονται στο πακέτο σας.
2. Στις <span class="sidebar-path">Ρυθμίσεις → Ρυθμίσεις καταστήματος</span> ενεργοποιήστε το `PRODUCT_SUGGESTIONS_ENABLED` (ανενεργό από προεπιλογή).

### Ορίστε εσείς τι προτείνεται για ένα προϊόν

1. Ανοίξτε το προϊόν στο <span class="sidebar-path">Κατάλογος → Προϊόντα</span> και πηγαίνετε στην καρτέλα **Σχετικά προϊόντα**.
2. Προσθέστε προϊόντα και διαλέξτε **Τύπο σχέσης**: **Παρόμοιο προϊόν**, **Ταιριάζει με**, **Αξεσουάρ για**, **Αντικατάσταση για** ή **Πακέτο με**.
3. Σύρετε τις γραμμές για να αλλάξετε τη σειρά. Αποθηκεύστε.

Η σχέση ισχύει προς μία κατεύθυνση: η θήκη στη σελίδα του κινητού δεν βάζει το κινητό στη σελίδα της θήκης. Αν θέλετε και τα δύο, προσθέστε τη σχέση και στα δύο προϊόντα.

### Αλλαγή μιας θέσης

1. Ανοίξτε τη θέση, π.χ. **Καλάθι**.
2. Αλλάξτε **Όριο**, **Ελάχιστη πλήρωση** ή **Λόγος εύρους τιμής**, ή αλλάξτε τη σειρά των κωδικών στην **Αλυσίδα στρατηγικών**. Αποθηκεύστε.
3. Για να κρύψετε τη λωρίδα σε αυτό το σημείο, ξετσεκάρετε **Ενεργοποιημένο**.

Αν κάτι πάει στραβά, πατήστε **Επαναφορά στις προκαθορισμένες ρυθμίσεις του καταστήματος** μέσα στη θέση, ή **Επαναφορά όλων των θέσεων στις προκαθορισμένες ρυθμίσεις του καταστήματος** πάνω από τη λίστα. Οι αλλαγές σας χάνονται.

## Καλό είναι να ξέρετε

- **Οι αλλαγές φαίνονται αμέσως.** Η αποθήκευση μιας θέσης, ενός προϊόντος ή μιας σχέσης ενημερώνει τις λωρίδες μόνη της.
- **Τι δεν προτείνεται ποτέ:** ανενεργά ή εξαντλημένα προϊόντα, και όσα είναι ήδη στο καλάθι.
- **Οι αρχικές ρυθμίσεις** κάθε θέσης εξαρτώνται από το είδος του καταστήματος (π.χ. ρούχα, φυτά, ηλεκτρονικά), που το ορίζει η ομάδα της πλατφόρμας.
- Τα **Βάρη** δείχνουν πόσο μετράει κάθε κωδικός (από 0 έως 1, προεπιλογή 1). Συνήθως δεν χρειάζεται να τα αλλάξετε.
- **Συμβάντα.** Το <span class="sidebar-path">Marketing → Συστάσεις → Συμβάντα</span> δείχνει, μόνο για ανάγνωση, κάθε **Προβολή** μιας λωρίδας, κάθε **Κλικ** σε προτεινόμενο προϊόν και κάθε **Προσθήκη**, δηλαδή προτεινόμενο προϊόν που κατέληξε σε παραγγελία. Από εκεί βλέπετε αν οι προτάσεις φέρνουν πωλήσεις.
- **Υποψήφια.** Το <span class="sidebar-path">Marketing → Συστάσεις → Υποψήφια</span> είναι συνήθως άδειο: οι τρόποι πρότασης που λειτουργούν σήμερα υπολογίζονται τη στιγμή που ανοίγει η σελίδα.
