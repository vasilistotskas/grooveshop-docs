# Images

Here you see every product and category image together. You use it mainly to change the order of a product's photos and to write a description for each image.

<span class="sidebar-path">Catalog → Images → Product Images</span> and <span class="sidebar-path">Catalog → Images → Category Images</span>

## What you see

**Product Images**: one row per photo, with the product, its SKU (product code) and **Is Main**. Search finds images by product name or SKU. The **Product** filter shows the photos of a single product.

**Category Images**: one row per category image, with the category, its **Type** and **Active**.

## Tasks

### Change the order of a product's photos
1. Open <span class="sidebar-path">Catalog → Images → Product Images</span>.
2. In the **Product** filter pick the product and apply.
3. Drag the rows into the order you want, then click **Save** at the bottom of the list. Until you save, the new order is not kept.

In the store the image marked **Is Main** always comes first. The rest follow in the list's order.

### Change the main photo
Open the photo, tick **Is Main** and save. The product's previous main photo loses **Is Main** automatically.

### Write a description (alt text) for a photo
You can do this from the product itself or from the photo's own page.

**From the product:**
1. Open the product and go to the **Product Images** tab.
2. Pick the language tab at the top of the page (for example Greek, then English).
3. In the row of each photo, fill in **Alt Text**, e.g. "Black USB-C cable, 2 metres".
4. Save, then repeat for each language you sell in.

**From the photo's page:**
1. Open <span class="sidebar-path">Catalog → Images → Product Images</span> and open the photo.
2. In the **Content** section, fill in **Alt Text** in every language tab.
3. Save.

The **Alt Text** is what people using a screen reader hear and what search engines read to understand the photo. Describe what is in the picture in a short sentence; there is no need to start with "image of". If you leave it empty, the store describes the photo itself with the product name and the photo's number in the gallery, e.g. "Mini Power Bank – photo 2".

Category images have an **Alt Text** per language, in the same section. On a category's **Main Image** it is the description the home page tile uses. If you leave it empty the photo gets no description of its own, which is fine: the category's name is written right below it.

## Things to know

- **Uploading**: new photos are easier to upload from the **Product Images** tab inside the product itself. The order cannot be changed there; that is what this list is for.
- **Files**: the usual image formats and SVG are accepted, up to 2.5 MB each.
- **One Is Main per product**: a product has at most one main photo. It is also the thumbnail in the product list.
- **Category images**: the store shows only each category's active **Main Image**. See [Categories](/admin/catalog/categories).
- When a product or a category is deleted for good, its images are erased too.
